
# 🌐 Página COVID-19 – Projeto de Bootcamp (2021)

Projeto desenvolvido durante minha **transição de carreira** para tecnologia, em 2021, como parte de um **bootcamp extremamente competitivo**, com mais de **400 participantes disputando apenas 20 vagas**.  
Este foi um dos meus primeiros projetos práticos na área de desenvolvimento web.

---

## 📌 Visão Geral  
O objetivo deste projeto foi criar um **site informativo e responsivo** sobre COVID-19, reunindo texto, vídeo, informações educativas e um formulário funcional de contato. O projeto reforçou conceitos essenciais de front-end e marcou o início da minha jornada em tecnologia.

---

## 🚀 O que foi desenvolvido  

### **Páginas do site**
- **Início:** apresentação e resumo do tema  
- **Sobre:** informações sobre COVID-19, sintomas e prevenção  
- **Mais:** conteúdos complementares e vídeo incorporado  
- **Contato:** formulário “Fale Conosco”

### **Funcionalidades**
- Layout responsivo com **HTML5, CSS3 e Bootstrap**
- Validação e interatividade com **JavaScript**
- Formulário funcional com campos obrigatórios
- Organização de conteúdo multimídia (texto + vídeo)

---

## 🛠 Tecnologias Utilizadas  
- **HTML5**  
- **CSS3**  
- **Bootstrap**  
- **JavaScript**  

---

## 🎯 Principais Aprendizados  
- Estruturação de páginas web com HTML semântico  
- Criação de layout responsivo com Bootstrap  
- Interatividade do usuário com JavaScript (validação e UX)  
- Organização e versionamento de projeto em Git/GitHub  
- Trabalho orientado a entregas em ambiente de bootcamp competitivo  

---

## 📁 Estrutura do Repositório  
- `index.html` — página inicial  
- `sobre.html`, `mais.html`, `contato.html` — páginas internas  
- `style.css` — estilos personalizados

Você pode executar o projeto localmente abrindo o arquivo **index.html** diretamente no navegador.
